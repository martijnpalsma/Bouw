# 📱 Bouw Informatie Systeem - iPhone Only Instructies

## 🌐 Het Systeem Online Zetten (Vanaf iPhone)

Omdat je alleen op iPhone werkt, moet het systeem online gehost worden. Hier zijn de beste opties:

---

## ✅ OPTIE 1: GitHub Pages (Aanbevolen - Gratis & Makkelijk)

### Via iPhone Browser (Safari):

1. **Open GitHub.com in Safari**
   - Ga naar: https://github.com/martijnpalsma/Bouw

2. **Ga naar Settings**
   - Scroll naar beneden
   - Tik op "Settings" tab (of "View all" → "Settings")

3. **Activeer Pages**
   - Scroll in het menu naar "Pages"
   - Onder "Source":
     - Selecteer: **cursor/brandweer-watervoorziening-agent-6057**
     - Of: **main** (als je de PR merged)
   - Tik op "Save"

4. **Wacht 2-3 minuten**
   - GitHub bouwt je site
   - Je krijgt een URL: `https://martijnpalsma.github.io/Bouw/`

5. **Open de URL op je iPhone**
   - Voeg toe aan Home Screen voor snelle toegang:
     - Tik op Share knop (📤)
     - Scroll naar "Add to Home Screen"
     - Tik "Add"
   - Nu heb je een app-icon op je iPhone! 📱

---

## ✅ OPTIE 2: Vercel (Nog Sneller - 1 Klik)

### Via iPhone:

1. **Open Vercel.com in Safari**
   - Ga naar: https://vercel.com/signup

2. **Sign in met GitHub**
   - Tik "Continue with GitHub"
   - Authorize Vercel

3. **Import Project**
   - Tik "Add New..." → "Project"
   - Selecteer "martijnpalsma/Bouw"
   - Tik "Import"

4. **Deploy**
   - Vercel detecteert automatisch dat het een static site is
   - Tik "Deploy"
   - **Klaar in 30 seconden!** 🚀

5. **Je krijgt een URL zoals:**
   - `https://bouw-martijnpalsma.vercel.app`
   - Of een custom domain die je zelf kunt kiezen

**Voordelen Vercel:**
- ⚡ Instant deploys bij elke update
- 🌍 Wereldwijd CDN (super snel)
- 🔒 Automatisch HTTPS
- 📱 Perfect voor iPhone
- 🆓 Gratis forever

---

## ✅ OPTIE 3: Netlify (Alternative)

### Via iPhone:

1. **Open Netlify.com in Safari**
   - Ga naar: https://app.netlify.com/signup

2. **Sign in met GitHub**

3. **Add New Site**
   - "Import from Git"
   - Selecteer je repository
   - Deploy!

**URL:** `https://bouw-martijnpalsma.netlify.app`

---

## 📲 Als het Online Staat:

### Add to Home Screen:

1. Open je site in Safari
2. Tik op Share knop (📤) onderaan
3. Scroll naar "Add to Home Screen"
4. Geef het een naam: "Bouw Systeem"
5. Tik "Add"

**Nu werkt het als een native app op je iPhone!** 🎉

### PWA Features (Optioneel):
Als je wilt dat het écht als app werkt (ook offline), kan ik een manifest.json en service worker toevoegen.

## 🆘 Hulp Nodig?

Als iets niet werkt:

1. **Check of je ingelogd bent** op GitHub
2. **Check repository permissies** (moet public zijn, of je moet owner zijn)
3. **Wacht even** - eerste deploy kan 2-5 minuten duren
4. **Clear Safari cache** - Settings → Safari → Clear History and Website Data
