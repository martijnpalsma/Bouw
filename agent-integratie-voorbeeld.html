🔗 Agent Integratie Voorbeeld

Deze pagina demonstreert hoe andere agents kunnen communiceren met de Brandweer & Watervoorziening Agent.

📋 Integratie Methoden

1️⃣ URL Parameters (Eenvoudig)

De eenvoudigste methode: stuur data via URL parameters.

// JavaScript voorbeeld
function sendToBrandweer(postcode, huisnummer) {
    const url = `brandweer-watervoorziening.html?postcode=${postcode}&huisnummer=${huisnummer}`;
    window.location.href = url;
    // Of voor nieuw venster:
    // window.open(url, '_blank');
}

✅ Voordelen

  • Zeer eenvoudig
  • Geen dependencies
  • Werkt overal

❌ Nadelen

  • Beperkte data
  • Zichtbaar in URL
  • Navigeert weg

2️⃣ LocalStorage (Persistente Data)

Gebruik LocalStorage voor complexere data die beschikbaar blijft.

// Agent A: Data verzenden
const locationData = {
    postcode: "1012 JS",
    huisnummer: "45",
    straatnaam: "Damstraat",
    plaats: "Amsterdam",
    extra: {
        gebouwType: "kantoor",
        verdiepingen: 5
    }
};
localStorage.setItem('brandweerAgentInput', JSON.stringify(locationData));
window.location.href = 'brandweer-watervoorziening.html';

// Brandweer Agent: Data ontvangen
const data = localStorage.getItem('brandweerAgentInput');
if (data) {
    const location = JSON.parse(data);
    // Gebruik de data...
    localStorage.removeItem('brandweerAgentInput'); // Opruimen
}

✅ Voordelen

  • Complexe data mogelijk
  • Persistent
  • Niet zichtbaar in URL

❌ Nadelen

  • 5-10MB limiet
  • Synchronous API
  • Opruimen nodig

3️⃣ PostMessage API (Cross-window)

Voor communicatie tussen verschillende vensters/iframes.

// Agent A: Open en verstuur
const brandweerWindow = window.open('brandweer-watervoorziening.html');

// Wacht tot venster geladen is
setTimeout(() => {
    brandweerWindow.postMessage({
        type: 'LOCATION_DATA',
        data: {
            postcode: "1012 JS",
            huisnummer: "45"
        }
    }, '*'); // In productie: specificeer origin
}, 1000);

// Brandweer Agent: Ontvang data
window.addEventListener('message', (event) => {
    // Valideer origin in productie!
    if (event.data.type === 'LOCATION_DATA') {
        const { postcode, huisnummer } = event.data.data;
        analyzeLocation(postcode, huisnummer);
    }
});

✅ Voordelen

  • Real-time communicatie
  • Bidirectioneel
  • Veilig (origin check)

❌ Nadelen

  • Complexer
  • Timing issues
  • Origin validatie nodig

4️⃣ REST API (Backend)

Voor productie: gebruik een backend API voor data uitwisseling.

// Backend endpoint (Node.js/Express voorbeeld)
app.post('/api/brandweer/analyze', async (req, res) => {
    const { postcode, huisnummer } = req.body;
    
    // Validatie
    if (!validatePostcode(postcode)) {
        return res.status(400).json({ error: 'Ongeldige postcode' });
    }
    
    // Analyseer
    const result = await analyzeBrandweer(postcode, huisnummer);
    res.json(result);
});

// Agent A: Request
const response = await fetch('/api/brandweer/analyze', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ postcode: "1012 JS", huisnummer: "45" })
});
const data = await response.json();

✅ Voordelen

  • Veilig
  • Schaalbaar
  • Validatie mogelijk
  • Rate limiting

❌ Nadelen

  • Backend vereist
  • Complexer setup
  • Hosting kosten

📝 Code Snippets

Postcode Validatie

function validateDutchPostcode(postcode) {
    // Nederlandse postcode: 1234 AB of 1234AB
    const regex = /^[1-9][0-9]{3}\s?[A-Z]{2}$/i;
    return regex.test(postcode);
}

function formatPostcode(postcode) {
    // Normaliseer naar 1234 AB format
    const cleaned = postcode.replace(/\s/g, '').toUpperCase();
    return cleaned.slice(0, 4) + ' ' + cleaned.slice(4);
}

Complete Integratie Functie

async function sendToBrandweerAgent(locationData) {
    // Validatie
    if (!validateDutchPostcode(locationData.postcode)) {
        throw new Error('Ongeldige postcode');
    }
    
    if (!locationData.huisnummer) {
        throw new Error('Huisnummer is verplicht');
    }
    
    // Format postcode
    locationData.postcode = formatPostcode(locationData.postcode);
    
    // Methode 1: URL Parameters (eenvoudig)
    if (window.INTEGRATION_METHOD === 'url') {
        const url = `brandweer-watervoorziening.html?` +
            `postcode=${encodeURIComponent(locationData.postcode)}&` +
            `huisnummer=${encodeURIComponent(locationData.huisnummer)}`;
        window.location.href = url;
        return;
    }
    
    // Methode 2: LocalStorage (meer data)
    if (window.INTEGRATION_METHOD === 'localstorage') {
        localStorage.setItem('brandweerAgentInput', JSON.stringify(locationData));
        window.location.href = 'brandweer-watervoorziening.html';
        return;
    }
    
    // Methode 3: PostMessage (cross-window)
    if (window.INTEGRATION_METHOD === 'postmessage') {
        const brandweerWindow = window.open('brandweer-watervoorziening.html');
        
        // Wacht tot venster geladen is
        return new Promise((resolve) => {
            setTimeout(() => {
                brandweerWindow.postMessage({
                    type: 'LOCATION_DATA',
                    data: locationData
                }, window.location.origin);
                resolve();
            }, 1000);
        });
    }
}
