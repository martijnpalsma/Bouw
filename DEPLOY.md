# 🚀 Deployment Instructies

## Voor iPhone-Only Gebruikers

### ✅ GitHub Pages (Gratis, Permanent)

**Direct Link om te Activeren:**
https://github.com/martijnpalsma/Bouw/settings/pages

**Stappen:**
1. Klik op link hierboven (ingelogd op GitHub)
2. Bij "Source": Selecteer `cursor/brandweer-watervoorziening-agent-6057` of `main`
3. Tik "Save"
4. Wacht 2-3 minuten
5. Open: https://martijnpalsma.github.io/Bouw/

---

### ⚡ Vercel (Instant Deploy)

**Direct Link:**
https://vercel.com/new/clone?repository-url=https://github.com/martijnpalsma/Bouw

**Of:**
1. https://vercel.com/signup
2. Sign in met GitHub
3. Import Repository
4. Deploy (30 sec)

---

### 🌐 Netlify (Alternative)

**Direct Link:**
https://app.netlify.com/start/deploy?repository=https://github.com/martijnpalsma/Bouw

**Of:**
1. https://app.netlify.com/signup
2. Sign in met GitHub
3. Import Repository
4. Deploy

---

## ✅ Deployment Checklist

Na deployment heb je:
- ✅ Live URL (werkt op elke iPhone/device)
- ✅ HTTPS secure verbinding
- ✅ Fast loading (CDN)
- ✅ Auto-updates (bij elke push naar main)
- ✅ Geen onderhoud nodig

---

## 📱 Add to Home Screen

Als het live staat:
1. Open de URL in Safari op iPhone
2. Tik Share knop (📤)
3. Scroll naar "Add to Home Screen"
4. Tik "Add"
5. Icon verschijnt op home screen!

Nu werkt het als een native app! 🎉

---

## 🔧 Configuratie Files

Dit repository bevat al alle configuratie:
- ✅ `manifest.json` - PWA configuratie
- ✅ `vercel.json` - Vercel settings
- ✅ `netlify.toml` - Netlify settings

---

## 🆘 Hulp Nodig?

**GitHub Pages werkt niet?**
- Check of repository public is
- Check of je owner/admin bent
- Wacht 5 minuten (eerste deploy duurt even)

**Vercel/Netlify werkt niet?**
- Sign in met GitHub
- Geef toegang tot repository
- Retry deploy

---
