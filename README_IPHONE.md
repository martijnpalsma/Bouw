# 📱 Bouw Systeem - Direct Gebruiken op iPhone

## 🚀 SNELSTE WEG: 3 Stappen

### Stap 1: Activeer GitHub Pages (1 minuut)

**Open op je iPhone in Safari:**
```
https://github.com/martijnpalsma/Bouw/settings/pages
```

Scroll naar "Build and deployment":
- **Source:** Selecteer `cursor/brandweer-watervoorziening-agent-6057`
- Tik **Save**

### Stap 2: Wacht 2 Minuten ⏱️

GitHub bouwt je site automatisch. Refresh de pagina om de status te zien.

### Stap 3: Open je Systeem! 🎉

```
https://martijnpalsma.github.io/Bouw/
```

Voeg toe aan Home Screen:
1. Tik Share knop (📤)
2. "Add to Home Screen"
3. Klaar! Nu heb je een app-icon 📱

## ⚡ Sneller? Gebruik Vercel

Als je instant deploys wilt:

1. Open https://vercel.com/signup
2. Sign in met GitHub
3. Import "martijnpalsma/Bouw"
4. Deploy (30 seconden!)

**Je krijgt:** `https://bouw-martijnpalsma.vercel.app`

Voordeel: elke push = automatisch online binnen 10 seconden
