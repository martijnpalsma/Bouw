Xcode Setup

Open het project in Xcode:

open FotoAnalyseApp/FotoAnalyseApp.xcodeproj

Project Structuur

FotoAnalyseApp/ ├── FotoAnalyseApp.xcodeproj └── FotoAnalyseApp/ ├── FotoAnalyseAppApp.swift # Main app entry ├── Views/ │ ├── ContentView.swift # Hoofd view │ ├── ResultsView.swift # Resultaten │ ├── CameraView.swift # Camera │ └── SettingsView.swift # Instellingen ├── Models/ │ └── AnalysisModels.swift # Data models ├── Services/ │ └── AnalysisService.swift # API service └── Resources/ └── Info.plist

Flask Backend Starten

De app heeft de Flask API nodig:

cd /workspace python app.py # Server draait op http://localhost:5000

App Configureren

In de app: Settings → API URL instellen op:

http://localhost:5000 # of http://YOUR_IP:5000

Code Highlights

API Service (Swift)

@MainActor class AnalysisService: ObservableObject { @Published var uploadState: UploadState = .idle @Published var currentAnalysis: AnalysisResponse? func uploadAndAnalyze(image: UIImage) async { uploadState = .uploading // Compress image guard let imageData = image.jpegData(compressionQuality: 0.8) else { return } // Create multipart form data var request = URLRequest(url: apiURL) request.httpMethod = "POST" request.setValue("multipart/form-data; boundary=\\(boundary)", forHTTPHeaderField: "Content-Type") // Upload & decode response let (data, _) = try await URLSession.shared.data(for: request) let response = try JSONDecoder().decode(AnalysisResponse.self, from: data) uploadState = .completed(response) } }

SwiftUI View

struct ContentView: View { @EnvironmentObject var analysisService: AnalysisService @State private var selectedImage: UIImage? var body: some View { NavigationStack { ZStack { LinearGradient(colors: [Color(hex: "667eea"), Color(hex: "764ba2")], startPoint: .topLeading, endPoint: .bottomTrailing) ScrollView { VStack { // Upload sectie PhotosPicker(selection: $selectedPhoto) { Label("Foto Bibliotheek", systemImage: "photo") } // Resultaten if case .completed(let response) = analysisService.uploadState { ResultsView(response: response) } } } } } } }
